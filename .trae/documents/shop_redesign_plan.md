# 商店页面重新设计计划

## 概述
根据用户的7项需求，彻底重新设计商店页面，使其更加简洁、实用，采用拼多多"多多买菜"风格的购物车系统。

**重要反馈（来自 AdvisorTool）**：
- 食材需手动精选，不是所有食谱食材都适合作为独立商品售卖（如"1碗蒸米饭"）
- 彻底移除 mealKit 概念，改为"套餐"方式——点击菜品可一键添加该菜品所需的全部食材
- 国家筛选应在两个商店中都生效

---

## 需求分析

### 需求清单
1. ✅ 地区选择器：移除国家图片，仅使用文字
2. ✅ 简化为两个商店：食材商店（Ingredients）和佐料商店（Condiments）
3. ✅ 优化布局：减少tab数量，消除拥挤感
4. ✅ 购物车系统：苹果买菜风格，浮动购物车栏
5. ✅ 优化图片和图标
6. ✅ 购买料理=购买该菜品的配料（套餐概念）
7. ✅ 商品基于现有食谱的食材

### 核心设计思路
- **双商店模式**：通过顶部两个大卡片切换"食材商店"和"佐料商店"
- **地区筛选**：仅使用国旗emoji+国家中文名，无图片
- **套餐概念**：在食材商店中展示各国招牌菜品，点击可一键添加该菜品所需的全部食材到购物车
- **商品体系**：精选自COUNTRIES数据中的可售食材
- **购物车**：拼多多风格——底部固定浮动栏，展开后显示所有商品

export type MealBundle = {
  id: string

## 风险与注意事项

1. **商品精选**：需确保每件商品都是食谱中可独立售卖的食材
2. **图片资源**：需为每件商品准备高质量 Unsplash 图片
3. **数据一致性**：商品 ID 需与 MEAL_BUNDLES 中的 items 对应
4. **性能**：购物车状态更新需使用 useMemo 优化
5. **无障碍**：确保所有按钮有 aria-label
6. **响应式**：确保在不同屏幕尺寸下布局合理
